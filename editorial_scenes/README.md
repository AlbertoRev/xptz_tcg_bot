2026-09-28. They contain no embedded Pokémon, text, logos or data; ReportLab
composites the weekly downloaded artwork and measured editorial copy above them.

| --- | --- | --- |

The renderer falls back to the existing map asset if a scene is unavailable.

keep the weekly PDF deterministic without requiring a paid image API at run time.
